## Timeline 1.0.0

Timeline is a desktop app for capturing and organizing ideas — one list, tags, statuses, and a description field that supports bullets, auto-detected links, and inline images. Everything is stored locally in SQLite; there's no account and no network access.

### Features

- Create, edit, and delete ideas.
- Track status: Incomplete, In progress, Completed.
- Free-form tags, with filtering by any combination of them.
- Live title search and newest/oldest sorting.
- Descriptions with bullet lists, automatic link detection, and images.
- Dark and light themes, with animations toggle.

### Download

Grab `Timeline-1.0.0-win-x64.zip` below, extract it anywhere, and run `Timeline.exe`.

This build isn't code-signed, so Windows SmartScreen may show *"Windows protected your PC"* on first launch. Click **More info → Run anyway**.

### Data

Your ideas are stored in `%USERPROFILE%\.timeline\` (database + any pasted images). That folder isn't touched by installing or removing the app, and it's what you'd back up or carry to another machine.

### Requirements

Windows 10/11, 64-bit. See the [README](https://github.com/maxey05/timeline#readme) for full usage details and what's planned next.
